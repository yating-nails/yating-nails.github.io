# 素材清單

## 網站使用素材

- `web/logo.png`：使用者提供的橫式品牌 Logo，原比例沿用。
- `web/favicon.ico`：由完整 Logo 縮放製作 16/32/48px icon。
- `web/assets/brand/apple-touch-icon.png`：180px；`icon-192.png`、`icon-512.png`：Manifest 圖示，皆保留完整標誌比例。
- `web/assets/brand/og-cover.jpg`：1200×630 分享封面。
- `web/assets/images/illustrations/`：24 張原創 SVG，對應 Hero 2、品牌氛圍 2、服務 13、保養細節 4，以及保養知識指南 3；不冒稱實景。
- 網站公開版未使用有權利疑慮的顧客手部照片、店面照片、價目海報或 LINE QR。
