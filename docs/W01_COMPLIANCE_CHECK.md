# YATING-W01 法規與宣傳文字檢查

檢查日期：2026-10-22

## 採用原則

網站服務以日常美容、清潔保養、指甲整理與舒適放鬆介紹。拔罐、刮痧及指壓相關內容僅作非醫療性民俗調理資訊，不作疾病診斷、治療或療效承諾。若有感染疑慮、傷口、出血、嚴重嵌甲、明顯紅腫、持續疼痛或疑似病變，網站提醒停止自行處理並尋求合格醫療專業評估。

官方依據：

- [衛生福利部民俗調理管理規範](https://dep.mohw.gov.tw/DOCMAP/fp-4388-39600-108.html) 及 [民俗調理業管理規範 PDF](https://www.mohw.gov.tw/dl-96942-0277a170-eea1-4067-8c16-7c05dda3e270.html)：民俗調理為傳統調理方式，避免宣稱醫療效能或使人誤認具有醫療效能。
- [醫療法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=L0020021)：醫療廣告的定義及醫療機構廣告限制，依現行法規文字檢視。
- [衛福部醫療廣告注意事項](https://www.mohw.gov.tw/cp-2704-43404-1.html)：整體文字及呈現方式均需留意是否造成醫療效能印象。

## 全站檢查結果

- 未以灰指甲、凍甲、指甲瘀血、感染等作為招攬服務名稱或效果承諾。
- 未宣稱根治、治療感染、消炎殺菌、醫療級治療、治癒嵌甲、排毒治病或改善特定疾病。
- 未使用病變前後照、顧客療效見證、虛構評價、星等或治療結果。
- 拔罐／刮痧服務使用「傳統」「放鬆」「民俗調理」語意，並提醒非醫療用途。
- 價格只按使用者提供資料呈現；舊版單色光療價格標示現行待確認。
- 未宣稱公休日或全年無休；僅列提供的 08:00–22:00，並提醒公休日須聯絡確認。
- 未虛構技師資格、品牌歷史、設備、官方社群或店內流程。
- 未公開來源授權與人物肖像同意未確認的照片；頁面使用清楚可辨識的原創 SVG 插畫，不冒稱實景。

## 限制

此檢查為網站文案與版面風險檢視，不構成法律意見。正式營運若新增服務、療效文案或顧客案例，需再次審查廣告整體意涵與圖片授權。
